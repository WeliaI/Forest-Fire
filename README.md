
# Нейросеть для обнаружения лесных пожаров

Свёрточная нейронная сеть для классификации изображений с лесными пожарами



## Установка

1. Клонирование репозитория:
```bash
  git clone https://github.com/WeliaI/Forest-Fire.git
  cd Forest-Fire
```

2. Создание виртуального окружения:
```bash
  python -m venv .venv
  .venv\Scripts\activate
```

3. Установка зависимостей:
```bash
  pip install -r requirements.txt
```

# Использование

1. Запуск приложения:
```bash
  python gui.py
```
2. В верхнем меню выберите Модели -> Выбрать модель (.keras) и выберите модель нейросети.
3. Используйте кнопки "Загрузить Фото" или "Загрузить Видео" для начала анализа.
4. Для остановки процесса и очистки экрана нажмите кнопку "Остановить".
